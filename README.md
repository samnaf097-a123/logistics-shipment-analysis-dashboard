# logistics-shipment-analysis-dashboard
Logistics shipment analysis using Excel, including data cleaning, pivot tables, dashboard, and business insights.
Logistics Shipment Analysis Dashboard
Project Overview

This project analyzes logistics shipment data using Microsoft Excel to evaluate delivery performance, carrier efficiency, shipment delays, and product-related issues. An interactive dashboard was created to present key metrics and business insights that can help improve logistics operations and delivery performance.

Project Objectives
Analyze delayed shipments and identify the hubs and carriers with the highest late delivery rates.
Compare average delivery time across carriers and shipment modes.
Identify product categories with the highest damaged and returned shipment rates.
Explore the relationship between shipment costs and delivery speed.
Analyze monthly shipment volume and on-time delivery trends from January to June 2024.
Tools Used
Microsoft Excel
Data Cleaning
Pivot Tables
Charts and Data Visualization
Interactive Dashboard
Dataset

The dataset contains logistics shipment records with information about shipment status, origin hubs, carriers, shipment modes, delivery dates, costs, and product categories.

The cleaned dataset contains 1,600 shipment records.

Key Findings
Total Shipments: 1,600
Delayed Shipment Status: 748 shipments (46.75%)
Highest Late Delivery Rate by Hub: Bengaluru (58.02%)
Highest Late Delivery Rate by Carrier: DTDC (57.82%)
Fastest Shipment Mode: Air (4.91 days average)
Slowest Shipment Mode: Road (8.49 days average)
Highest Damaged/Returned Rate: Electronics (10.98%)
Highest Monthly Shipment Volume: March 2024 (295 shipments)
Lowest Monthly On-Time Delivery Rate: March 2024 (42.03%)
Dashboard

The Excel dashboard contains charts and visualizations to explore shipment performance, delivery delays, carrier efficiency, product issues, and monthly trends.

Business Recommendations
Investigate delivery delays at Bengaluru hub and review DTDC's delivery performance.
Review road shipment processes to identify opportunities to reduce delivery time.
Improve packaging and handling for electronics shipments.
Monitor monthly shipment volume and on-time delivery performance.
Compare carrier costs with delivery performance before making carrier allocation decisions.
Conclusion

This project demonstrates how Microsoft Excel can be used to clean logistics data, perform analysis, create an interactive dashboard, and generate actionable business insights.

The findings can help logistics teams identify operational problems and make data-driven decisions.
